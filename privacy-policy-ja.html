施行日： 2026年5月16日

1. はじめに

ThoughtsSky（以下「本アプリ」）は、個人開発者 Hung Chen-Jung（以下「当方」）が提供する、思考や感情の記録・整理・振り返りを支援するアプリです。

本アプリを利用することで、本プライバシーポリシーに同意したものとみなします。同意いただけない場合はご利用をお控えください。

3. 収集するデータと利用目的

3.1 アカウントデータ

  • 内容： メールアドレス、パスワード（Firebase Authentication がハッシュ等で安全に保存。当方は平文パスワードを読み取れません）、Firebase ユーザー ID（UID）。匿名ログインも可能です。
  • 目的： アカウント作成・管理、認証、パスワード再設定、データとアカウントの紐付け、アカウント削除。

3.2 ユーザーが提供するコンテンツ（思考の記録）

  • 内容： 入力または音声入力で作成したテキスト（1件最大500文字）、雲の種類（灰／金／白）、選択した領域・感情・思考の癖タグ、作成・変換日時、灰雲から金雲への変換前後のテキストなど。
  • 保存先： Google Cloud Firestore（users/{あなたのUID}/thoughts）。Firestore セキュリティルールにより本人のみアクセス可能。
  • 目的： 記録、カレンダー表示、統計（宝箱）、変換、編集などの中核機能。

3.3 音声入力

  • 内容： マイク使用時、音声は Android の音声認識サービス（通常 Google）で処理され、テキスト化されます。当方のサーバーに音声ファイルは保存しません。
  • 目的： 音声による思考入力（任意）。録音は最大約45秒。停止・キャンセル・戻る・保存・アプリ終了で終了できます。

3.4 サブスクリプションと支払い

  • 内容： Google Play 課金で処理されるサブスクリプション状態等（Google が提供。当方はカード番号等を保存しません）。
  • 目的： サブスクリプション特典の確認（例：カレンダー履歴の解放）。

3.5 フィードバック

  • 内容： 機能提案・不具合報告（最大500文字）、アカウントメール（匿名の場合は anonymous）、UID、アプリバージョン、送信日時。
  • 保存先： Firestore の feedback コレクション（製品改善用。他ユーザーは閲覧不可）。
  • 目的： フィードバック対応とデバッグ。

3.6 端末・アプリ設定

  • 内容： 選択した UI 言語（繁体字中国語、English、日本語）。端末内 SharedPreferences に保存。
  • 目的： 言語に応じた UI 表示。

3.7 ギャラリーへの保存（ユーザーの操作）

  • 内容： 週間カード画像のダウンロード時、Android MediaStore 経由で端末ギャラリーに保存。当方サーバーへは別途アップロードしません。

3.8 現バージョンで収集しない項目

本アプリは GPS 位置情報、広告トラッキング SDK、Firebase Analytics（現行コードベース）を使用していません。変更時は本ポリシーを更新します。

4. 端末の権限

権限 用途 必須
インターネット Firebase、Google Play 課金 はい
ネットワーク状態 接続確認 はい

6. 保存期間と削除

  • 保存期間： 利用中はアカウントと思考データを保持。現時点で自動削除スケジュールはありません。
  • アカウント削除： アプリの「アカウント」から削除可能。Firestore の思考データと Firebase Auth アカウントを削除します。復元不可です。
  • フィードバック： 改善のため保持。削除希望はメールでご連絡ください。

7. セキュリティ

HTTPS、Firebase セキュリティルール等で保護します。完全な安全は保証できません。アカウント情報の管理はご自身でお願いします。

8. 子どものプライバシー

本アプリは 13歳未満 を対象としていません。13歳未満から故意にデータを収集しません。保護者の方はご連絡ください。
